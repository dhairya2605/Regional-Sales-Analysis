# Regional Sales Analysis

## Overview

This project analyzes historical sales data to identify trends in revenue, profit, product performance, customer segments, sales channels, and regional performance.

The analysis combines **Python-based exploratory data analysis** with an **interactive Power BI dashboard** to generate actionable business insights.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly
* Power BI
* Power Query
* Microsoft Excel

## Dataset

The project uses historical sales data covering **2014–2018**, including information related to:

* Sales transactions
* Customers
* Products
* Regions
* Sales channels
* Budgets

Multiple datasets were cleaned and combined to create a unified dataset for analysis.

## Project Workflow

1. **Data Cleaning**

   * Checked for missing values and duplicates
   * Standardized columns and data types
   * Prepared datasets for analysis

2. **Data Integration**

   * Combined sales, customer, product, regional, and budget data
   * Created a consolidated dataset for analysis

3. **Exploratory Data Analysis**

   * Analyzed revenue and profit trends
   * Evaluated product and regional performance
   * Studied sales channels and customer segments
   * Identified seasonal patterns and key business drivers

4. **Feature Engineering**

   * Calculated revenue, cost, profit, and profitability metrics
   * Created additional analytical features for business analysis

5. **Visualization**

   * Created charts using Matplotlib, Seaborn, and Plotly
   * Developed an interactive Power BI dashboard for KPI monitoring and business insights

## Key Analysis Areas

* Revenue and profit trends
* Regional sales performance
* Product performance
* Sales channel comparison
* Customer segment analysis
* Budget vs. actual performance
* Seasonal sales patterns
* Profitability analysis

## Dashboard

The Power BI dashboard provides an interactive view of key business metrics, allowing users to explore sales performance across different regions, products, channels, and time periods.
